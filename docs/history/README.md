# History / receipts

Este directorio está reservado para receipts y documentos superados durante la implementación.

Reglas:

- un receipt registra evidencia de un SHA exacto;
- no se usa como autoridad de estado actual;
- `ROADMAP.md` sigue siendo la única autoridad de secuenciación;
- al superseder una decisión, no se reescribe la evidencia histórica: se crea ADR/receipt nuevo y se enlaza la supersesión.
