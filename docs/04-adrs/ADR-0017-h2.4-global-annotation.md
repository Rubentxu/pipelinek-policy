# ADR-0017 — H2.4 GLOBAL execution: keep refusal tipado, GLOBAL is a forward-compat annotation

**Status:** ACCEPTED · **Fecha:** 2026-10-11 · **Agente:** Jcode · **Work-item:** `6fb5b421-1201-4773-b748-e6510da8b87b`

## Decision

**Adopt Alternative C from `docs/history/R2_1_H24_DESIGN_FORK.md`.**

- `DatasetShape.GLOBAL` remains a shape annotation in the IR (per `POLICY_IR.md` §9).
- `DatasetSpec.requiresGlobalIndex: Boolean` is preserved as a DECLARATION field (serialized in the bundle; visible to tooling).
- `DatasetPlanner.plan()` continues to refuse any rule whose shape is GLOBAL with the typed `PlanRefusal(GLOBAL_WITHOUT_INDEX)` (law 12).
- `StreamingEvaluator` does NOT implement the GLOBAL execution path; the sealed `IndexPlan.InMemoryIndex` member remains in the ADT but is never emitted by the planner.
- The previous `@Suppress("UnusedParameter")` on `DatasetPlanner.plan()`'s `datasets: Map<String, DatasetSpec>` parameter is the seam that future H2.4 work will close: the parameter is load-bearing once the executor lands.

## Rationale (drawn from R2.1)

1. **R2.1 architectural preference clause, literal reading:** "antes que introducir una capacidad parcial o un índice ficticio". A coarse-grained `requiresGlobalIndex` consumer (Alt A) IS a capability partial; a per-rule `requiresDatasetIndex` consumer (Alt B) IS another capability partial; both introduce a code path that the v0.3.x cycle cannot test end-to-end against a measured use case. C does not introduce any new capability.
2. **Cost asymmetry:** A = low cost, medium risk; B = high cost (touches the canonical IR), high risk; C = zero cost, zero risk.
3. **Migration safety:** A and B both need product-owner sign-off on a measured use case. C does not block future work — when a use case lands, an ADR (probably `ADR-0018-h2.4-global-executor.md`) reopens H2.4 and re-picks A vs B.
4. **No silent downgrade:** the refusal is typed (`PlanRefusal(GLOBAL_WITHOUT_INDEX)`); the field is still serialized; the IR still carries the annotation. There is no silent weakening of an upper-layer rule (architectural law 12 stays intact).

## Consequences

- **Documentation:** `POLICY_IR.md` §9 already documents GLOBAL as a static cost annotation; no edit required. This ADR adds the explicit "the executor is not implemented in v0.3.x" sentence.
- **Tests:** the 14 sites identified by `02fd23e` (13 tests in 7 files + 1 production in `CanonicalPolicyJson:147`) continue to be covered by the existing refusal tests. No new tests required.
- **Implementation:** zero code change. The current state already implements C.
- **v0.4.0+ trigger:** if a user reports a real use case that needs GLOBAL with materialization, open a new H2.4 cycle and pick A or B from the comparison in R2.1.
